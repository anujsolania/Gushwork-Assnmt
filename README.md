# Gushwork Assignment

Responsive, single-page marketing layout built with vanilla HTML, CSS, and JavaScript.

## Project Structure
- index.html - Main page markup
- styles.css - Layout, styling, and responsive rules
- script.js - Sticky header, carousel, zoom, and FAQ interactions
- assets/ - Images and placeholder SVG assets

## Features
- Sticky header that appears after the first fold
- Image carousel with hover zoom preview
- Responsive sections across desktop, tablet, and mobile
- Accessible markup patterns and smooth transitions

## How to Run
Open index.html in your browser. No build tools or dependencies required.

## Notes
- Replace placeholder assets in assets/ with final exports from Figma for pixel-perfect output.
- Typography uses Google Fonts (Plus Jakarta Sans).
